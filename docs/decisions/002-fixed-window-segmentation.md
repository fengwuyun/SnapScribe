# ADR-002: 固定窗音频切片作为分段转录策略

状态：已接受 · 日期：2026-07（开发期）

## Decision

FFmpeg 在转码为 16kHz 单声道 PCM 的同一条命令中用 `-f segment -segment_time 60` 切片；Rust 对切片严格串行转录，每段完成即推送事件。

## Context

新增需求要求先切分以降低单次转录负载，并按段渐进展示。备选方案：整条音频一次推理（无渐进、内存峰值高）；VAD 全程分段后按语音区间切割（需额外一遍 VAD 扫描与更复杂的拼接）。

## Reason

一条 FFmpeg 命令同时完成提音轨/统一格式/切片，无双重 IO；PCM 无关键帧约束，切割精确；段数即进度粒度，事件协议简单；串行执行保证时间戳单调、取消语义简单。

## Trade-offs

固定窗切割点可能落在词中间（每段最多影响首尾一个词）。MVP 接受；改进方向是 silencedetect/VAD 对齐的静音切割，本期不做。段时长默认 60s，代码中为常量，不做用户配置。
